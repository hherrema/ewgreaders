Steps to build Eawag conda environment.

1. conda create --name ewg python=3.13
2. conda install mamba
3. mamba install pandas
4. mamba install scipy
5. mamba install matplotlib
6. mamba install seaborn
7. mamba install xarray dask netCDF4 bottleneck
8. mamba install ipykernel
9. mamba install tqdm
10. mamba install gsw
11. pip install envass seawater pyRSKtools dateparser python-dateutil
12. pip install dolfyn
13. pip install -e ewgreaders
